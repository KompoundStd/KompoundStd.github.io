# KompoundStd website

A static site for GitHub Pages: `index.html`, `style.css`, `site.js`, `assets/`.

- **Links and contact:** fill in `SITE` at the top of `site.js` (Steam page, itch.io page, email, socials). Empty
  ones show "coming soon" or are left out.
- **Media:** the trailer and clips come from the game's `Recordings/` (720p trailer, 960x540 clips, the 780x80
  section headers); screenshots are the Steam ones, as JPG plus 640 px thumbnails.
- **Preview locally:** any static server, e.g. `node serve.js "E:/KompoundStd Website" 8731`.
